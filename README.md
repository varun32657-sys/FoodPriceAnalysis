# Food Price Analysis System

## Course
COMP 8547 – Advanced Computing Concepts

## Term
Winter 2026

## Project Description

The Food Price Analysis System is a Java-based desktop application that allows
users to search for grocery products and compare prices across multiple stores.

The system uses grocery datasets from stores such as Loblaws, Sobeys, No Frills,
Food Basics, FreshCo, and Superstore.

## Main Features

- Product search
- Price comparison
- Search suggestions
- Spell checking
- Search ranking
- Product filtering
- Wishlist/favorites
- Search history
- User registration and login
- Multiple grocery store datasets

## Technologies

- Java
- Java Swing
- Maven
- CSV
- Data Structures and Algorithms

## Data Structures and Algorithms

- HashMap / Inverted Index
- Trie
- Edit Distance
- Priority Queue / Min Heap
- TreeMap
- Boyer-Moore
- Java Stream API
